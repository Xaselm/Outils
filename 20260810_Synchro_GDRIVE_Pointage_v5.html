🌗 Demi-journée d'absence

La moitié des heures théoriques du jour est retirée ; saisissez les horaires de la demi-journée travaillée.

Une journée d'absence ne compte ni dans les heures réelles, ni dans les heures théoriques. Pour une demi-journée d'absence avec une demi-journée travaillée, choisissez plutôt Présentiel / Télétravail / Déplacement puis « Demi-journée d'absence ».

⚙️ Paramètres

Heures théoriques par jour

En heures décimales (ex : 7.5 = 7 h 30). Mettre 0 pour un jour non travaillé — ces jours sont hachurés dans le calendrier.

Types d'absence et droits annuels

LibelléDroit / an

Droit annuel en jours (facultatif, ex. 25 pour les congés payés) : il alimente le solde affiché dans le bilan annuel. Laisser vide pour un simple décompte.

Jours fériés

Un jour férié est hachuré dans le calendrier et ne compte pas dans les heures théoriques.
