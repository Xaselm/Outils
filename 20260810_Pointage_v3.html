Journée

La pause est facultative — laissez vide si absente.

Ce jour ne comptera ni pour les heures réelles, ni pour les heures théoriques de la semaine.

Paramètres

Heures théoriques par jour

En heures décimales (ex : 7.5 = 7 h 30). Mettre 0 pour un jour non travaillé — ces jours seront grisés dans le calendrier.

Types d'absence

Jours fériés

Un jour férié est automatiquement grisé et ne compte pas dans les heures théoriques.

Synchronisation Google Drive

À créer une fois dans Google Cloud Console : activer l'API Google Drive, créer un identifiant OAuth « Application Web », et ajouter l'adresse à laquelle ce fichier est hébergé (ex : votre page GitHub Pages) dans « Origines JavaScript autorisées ». Ne fonctionne pas en ouvrant le fichier en local (file://) — il doit être servi en http/https. L'ID client est enregistré avec vos données, pas besoin de le ressaisir à chaque export.
